# カメラ案の実装・検証記録

対象: `/Users/devonly/Developer/QRReader`、ホスト `studio`、Xcode 27。

## 実装

- カメラの全面プレビュー、白い読み取り枠、2タブ、設定入口を採用。
- 操作アイコン24pt、タブ28pt、44pt以上のタップ領域。
- URL／テキスト／履歴の結果を同じネイティブシートで表示。内容をスクロールし、コピー・共有・リンク操作を保持。
- 大きな文字では結果ボタンを縦に並べ、長いタイトルと日時をスクロール領域へ移動。
- 初回案内は1ページ。カメラ権限を明示操作で要求し、設定からの案内再表示も維持。
- スキャンの連続通知と古いセッションの通知を抑止し、タブ・画面状態・シート・権限に応じて再開。
- `QR_HISTORY` のJSON文字列、UUID、日時の保存形式を維持。壊れた保存内容は自動上書きせず、保存できない結果には案内を表示。
- XcodeGenの定義と依存ロックを追加。Firebase設定のないDebugでも起動可能。
