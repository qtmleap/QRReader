# QR Reader 主要画面スクリーンショット

2026-10-14 / iPhone 16 / iOS 26.5 / 日本語

実アプリをシミュレータで起動して取得しました。カメラ背景には検証用の代替表示を使用しています。
各PNGは1178 × 2556 pxの原本です。トリミングや縦横比の変更はしていません。

index.htmlをブラウザで開くと全画面を一覧できます。overview.pngは主要6画面、states-overview.pngは状態別3画面、settings-overview.pngは設定から開く3画面の一覧です。

- 01-scan.png: スキャン
- 02-result-url.png: 読み取り結果：URL
- 03-result-text.png: 読み取り結果：テキスト
- 04-history.png: 履歴
- 05-settings.png: 設定
- 06-welcome.png: 初回案内・使い方
- 07-history-empty.png: 履歴が空の状態
- 08-camera-denied.png: カメラ権限の案内
- 09-share.png: 共有シート
- 10-result-long-url.png: 長いURLの読み取り結果
- 11-contact.png: お問い合わせ
- 12-developer.png: 開発者
- 13-licenses.png: ライセンス

manifest.jsonに元のテスト結果とSHA-256を記録しています。
